# Remix of Remix of Remix of Remix of Remix of Study Buddy Planner

"Build a mobile-friendly Study Planner web app for Matric (Grade 9–10) students. The target users have little tech experience, so the design must be extremely simple, clean, and intuitive — large buttons, minimal text, clear icons, no clutter.

Overall style: Friendly, modern, calming color palette (soft blues/greens), rounded cards, generous spacing, big readable fonts. Bottom navigation bar for mobile (Home, Subjects, Schedule, Progress).

Core features:

Home/Dashboard screen — shows today's date, a countdown to the nearest exam, today's study tasks at a glance, and a motivational quote.

Subjects & Exams — students can add subjects (e.g., Math, Physics, Urdu) with exam dates. Each subject shows a countdown and a color tag.

Auto Study Schedule Generator — student enters exam dates and how many hours/day they can study; app automatically distributes topics/subjects across the available days into a simple daily plan (no manual scheduling needed).

Topic Checklist — under each subject, a checklist of topics/chapters the student can mark as 'Not started / In progress / Completed,' with a progress bar per subject.

Daily Task View — simple checkbox list of today's planned study tasks, satisfying to check off.

Progress Tracker — a simple overview page showing overall completion percentage per subject with a visual bar or circular chart.

Reminders/Notifications (visual only is fine) — a gentle banner reminding the student of tomorrow's tasks or upcoming exam.

Usability requirements:

Every action should take 1–2 taps max

Use icons + short labels together (not icon-only, since users are less tech-savvy)

Include short helper text/tooltips on first use (e.g., 'Tap + to add your first subject')

Empty states should guide the user (e.g., 'No subjects yet — add one to get started')

Make it fully functional with working navigation, add/edit/delete for subjects and tasks, and data that persists during the session."
